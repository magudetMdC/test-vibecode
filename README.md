# Jeux web de Marie-Anne 🎃💖

Quelques petits jeux web, sans installation : tout tourne dans le navigateur.

👉 Site en ligne : https://magudetMdC.github.io/test-vibecode/

## 🎃 Snake d'Halloween (page d'accueil)

Un Snake sur le thème d'Halloween : attrape les citrouilles, contourne le mur central
et évite de mordre ta propre queue.

- Déplacement aux flèches du clavier (ou ZQSD / WASD), pavé tactile sur mobile
- Mur central en forme de croix qui complique le parcours
- Score, niveau et record sauvegardé dans le navigateur
- Pause avec `Espace`, redémarrage avec `R`

Fichier : `index.html`

## 💖 Démineur Cœurs

Un démineur (Minesweeper) revisité où les bombes sont remplacées par des cœurs.

- Grille carrée 30×30
- Les bombes sont des cœurs 💖
- Clic gauche pour révéler une case, clic droit pour poser un drapeau 🚩
- Nombre de cœurs réglable
- Première case toujours sûre
- Révélation automatique des cases vides
- Compteurs colorés selon le nombre de cœurs adjacents

Fichier : `minesweeper.html`

## 🎡 Roue des tâches

La roue de la semaine : chacun tourne à son tour et la roue choisit sa tâche.

- 6 tâches, 4 membres, une tâche par personne
- Tirage honnête, sans remise : une tâche tirée quitte la roue
- Ordre de passage tournant d'une semaine sur l'autre
- Tirage le dimanche soir pour la semaine qui commence
- Son, confettis, bilan de fin de semaine, annulation du dernier tour
- Tâches modifiables dans la page (5 à 8), semaine conservée dans le navigateur

Fichier : `roue-taches/index.html`
